Example 1.7.2.

Autonomous equations have particularly nice slope fields.
🔗
Consider the differential equation
\begin{equation*} \dfrac{dy}{dx} = 0.1x(2-x) \end{equation*}
This is of the form given by Example 1.2.6, so we should expect solutions to look like logistic functions. Indeed, solving results in
\begin{equation*} y(x) = \dfrac{5}{1+Ce^{0.5x}} \end{equation*}
for some constant \(C\text{.}\) The resulting slope field takes the form below.
🔗
The blue solution curves correspond to initial values for which the solution is bounded below by 0 and grows to the carrying capacity of the system; the red solution curves show initial values below zero, and the green solution curves show initial values above \(y(x) = 5\text{.}\)
🔗
Note the horizontal lines which create asymptotes for the solution curves. We call these output values equilibrium solutions
