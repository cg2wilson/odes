    Section FO1: Solutions to Differential Equations

    Objectives

    • I can determine if a function or family of functions is a solution to a given differential equation, classify a differential equation as linear or nonlinear, and identify its order.
      🔗
      🔗
    🔗

    Subsection What Is a Differential Equation?

    Definition 1 (Ordinary/Partial) Differential Equation.

    A differential equation is an equation which relates a function to its derivatives. There are two kinds of differential equations: ordinary differential equations (ODEs) and partial differential equations (PDEs). In this course, we will restrict our focus to ordinary differential equations.
    🔗
    🔗

    Example 2.

    An example of an ordinary differential equation is the familiar
    \begin{gather*} \dfrac{dy}{dx} = 2x \end{gather*}
    which asks the question: "What function y(x) has a derivative equal to 2x?" The solution to this differential equation is the family of functions
    \begin{equation*} y(x) = x^2 + C \end{equation*}
    where C is an arbitrary constant. We can check that this is a solution by differentiating; \(\dfrac{d}{dx}(x^2 + C) = 2x\text{,}\) so we have have satisfied the condition stated by the differential equation.
    🔗
    🔗

    Example 3.

    Other examples of ordinary differential equations are
    \begin{equation*} \dfrac{dy}{dx} = ky \end{equation*}
    \begin{equation*} \sin(t) + x''(t) + x'(t) = t \end{equation*}
    \begin{equation*} xe^x + \lrpar{\dfrac{dy}{dx}}^2 = 0 \end{equation*}
    🔗
    🔗

    Example 4.

    Below are examples of partial differential equations:
    🔗
    The wave equation:
    \begin{equation*} \dfrac{\partial^2f}{\partial x^2} = \dfrac{\partial^2f}{\partial t^2} \end{equation*}
    🔗
    The heat equation:
    \begin{equation*} c^2 \dfrac{\partial^2f}{\partial x^2} = \dfrac{\partial f}{\partial t} \end{equation*}
    🔗
    🔗
    🔗

    Subsection Testing Solutions to ODEs

    Definition 5 Solution to a Differential Equation.

    A solution to a differential equation is a function which satisfies the rules imposed by the equation.
    🔗
    🔗

    Example 6.

    The family of functions \(y(x) = x^2 + C\) are solutions to the differential equation
    \begin{equation*} \dfrac{dy}{dx} = 2x \end{equation*}
    because \(y'(x) = \dfrac{dy}{dx} = 2x\)
    🔗
    🔗

    Example 7 Exponential Growth.

    The family \(x(t) = Ce^{kt}\) is a solution to the differential equation
    \begin{equation*} x'(t) = ax \end{equation*}
    for some constant \(a\in \R\) because \(x'(t) = Cke^{kt}\) and \(x''(t) = Ck^2e^{kt}\text{.}\) Setting \(a = k^2\text{,}\) we have \(x''(t) = aCe^{kt} = ax(t)\text{.}\)
    🔗
    This differential equation models exponential growth. In reality, few things grow exponentially due to constraints in the environment. Despite its lack of realism, we can use the exponential growth equation to help build other, more useful models.
    🔗
    🔗

    Example 8.

    The acceleration of an object in free-fall is given by \(a(t) = \dfrac{d^2s}{dt^2} = -g\) where \(g\) is the gravitational constant. Find its position function, knowing that \(s(0) = 1000\)m and \(v(0) = -25\)m/s.
    🔗
    You likely would have encountered this kind of problem when learning integration/antiderivatives; the solution requires integrating acceleration to find velocity and then using velocity to find position. First, we have
    \begin{equation*} v(t) = \dfrac{ds}{dt} = -gt + C \end{equation*}
    Since \(v(0) = -25\text{,}\) we have \(C = -25\) and \(v(t) = -gt - 25\text{.}\) Next, we integrate again to find position:
    \begin{equation*} s(t) = \dfrac{-gt^2}{2} - 25t + C \end{equation*}
    Since \(s(0) = 1000\text{,}\) we have \(C = 1000\) and \(s(t) = \dfrac{-gt^2}{2} - 25t + 1000\text{.}\)
    🔗
    🔗

    Let \(f_1(x) = c_1x\text{,}\) \(f_2(x) = c_2x^2\text{,}\) and \(f_3(x) = c_3x^{-1}\text{.}\) Show that each of these functions is a solution to the differential equation

    Theorem 12 Principle of Superposition.

    Linear combinations of solutions to a differential equation are also solutions to the same differential equation.
    🔗
    🔗
    🔗

    Subsection Classifying Differential Equations

    Definition 13 Linear/Nonlinear Differential Equations.

    A differential equation is linear if it can be written in the form
    \begin{equation*} a_n(x)y^{(n)} + a_{n-1}(x)y^{(n-1)} + \cdots + a_1(x)y' + a_0(x)y = g(x) \end{equation*}
    where the coefficients \(a_i(x)\) and \(g(x)\) depend only on the independent variable \(x\text{.}\) Otherwise, the differential equation is nonlinear.
    🔗
    🔗

    Definition 14 Order of a Differential Equation.

    The order of a differential equation is the order of the highest derivative in the equation.
    🔗
    🔗

    Definition 15 (Non)Homogeneous Differential Equation.

    A differential equation is homogeneous if all terms depend on the dependent variable, i.e. if no term is a function of the independent variable alone. Otherwise the equation is nonhomogeneous.
    🔗
    🔗

    Note 16.

    A homogeneous, linear ODE can always be put into the form
    \begin{equation*} a_n(x)\dfrac{d^ny}{dx^n} + a_{n-1}(x)\dfrac{d^{n-1}y}{dx^{n-1}} + \cdots + a_1(x)\dfrac{dy}{dx} + a_0(x)y = 0 \end{equation*}
    🔗
    🔗

    Example 17.

    The equation
    \begin{equation*} y''' - x^2y' + y = 0 \end{equation*}
    has order 3, is linear, and homogeneous. However,
    \begin{equation*} y''' - x^2y' + y = x \end{equation*}
    is nonhomogeneous.
    🔗
    🔗
